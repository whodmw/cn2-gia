## 机房切换怎么操作，有哪些坑

切换本身很简单：登录 KiwiVM 控制面板，左侧找 Migrate to another DC，选目标机房确认即可。免费，数据完整保留，不需要重装系统。

要注意的细节有四个：

- **IP 会变**。迁移后分配新 IP，如果你的业务绑定了固定 IP 或有白名单需求，先想清楚。
- **有冷却时间**，约 5 小时，不能连续反复迁。
- **各套餐范围不同**。CN2 GIA-E 可选 12 个机房；KVM 套餐只能在普通线路机房里切换；香港、日本 CN2 GIA 不可迁移；EUNL_1 只接受新购迁入。
- **切换有次数限制**，日常调整够用，但别把它当成可以天天换的玩具。

下单前还有个笨但有效的办法：网上能查到各机房的测试 IP，买之前先 ping 一下、看看路由，比自己猜靠谱得多。
